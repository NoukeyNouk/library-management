# Library Management (Менеджер библиотеки)

Простая консольная программа на C++ для учёта книг в библиотеке, регистрации читателей и контроля за выдачей книг.

---

## Что умеет программа

- **Книги**:
  - Добавлять и удалять книги (название, автор, жанр, номер ISBN).
  - Искать книги по названию, автору, жанру или ISBN.
  - Показывать весь список доступных книг.

- **Читатели**:
  - Регистрировать новых читателей и удалять их.
  - Искать читателя по имени.
  - Поддерживает 3 категории пользователей со своими лимитами:
    - **Студент** (`Student`): до 3 книг на срок до 14 дней.
    - **Преподаватель** (`Faculty`): до 10 книг на срок до 30 дней.
    - **Гость** (`Guest`): 1 книга на срок до 7 дней.

- **Выдача и возврат**:
  - Выдавать книги читателям (с проверкой, свободна ли книга и не превышен ли лимит читателя).
  - Принимать книги обратно (закрывать запись о выдаче).
  - Смотреть историю всех выдач (активные и уже возвращённые).
  - Переключать день на следующий (счётчик дней).
  - Показывать список должников (тех, кто не вернул книги вовремя).

---

## Как собрать и запустить

### Сборка
```bash
make
```

### Запуск
```bash
./manager
```

---

## Меню команд

После запуска появится список доступных действий:

| Номер | Команда | Что делает |
| :---: | :--- | :--- |
| `1` | `add new book` | Добавить новую книгу |
| `2` | `remove book from library` | Удалить книгу из каталога |
| `3` | `find book` | Найти книгу (по названию, автору, жанру или ISBN) |
| `4` | `show all books` | Показать все книги библиотеки |
| `5` | `add new user` | Добавить нового читателя |
| `6` | `remove user` | Удалить читателя |
| `7` | `find user` | Найти читателя по имени |
| `8` | `show all users` | Показать список всех читателей |
| `9` | `new record` | Оформить выдачу книги читателю |
| `10` | `close record` | Принять книгу обратно (закрыть выдачу) |
| `11` | `show history` | Показать историю выдач (активные и закрытые) |
| `12` | `view overdue books` | Показать просроченные книги и должников |
| `13` | `advance to next day` | Перемотать время на 1 день вперёд |
| `0` | `quit` | Выйти из программы |

## 📁 Структура файлов

- `src/main.cpp` — главное меню программы и обработка команд.
- `src/library.hpp` — общая логика управления библиотекой.
- `src/book.hpp` — структура данных книги.
- `src/users.hpp` — классы пользователей и их лимиты по книгам и дням.
- `src/record.hpp` — система учёта выдачи книг, подсчёт дней и сроков сдачи.
- `Makefile` — файл для быстрой сборки одной командой.
